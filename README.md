🚀 AlgoTrack

Your Personal Data Structures & Algorithms Tracker

AlgoTrack is a personal DSA tracking application built to help developers organize their problem-solving journey, track coding progress, and build consistent coding habits.

The goal is to make DSA preparation more structured, measurable, and productive.

✨ Features

- Track coding problems.
- Organize problems by topic and difficulty.
- Maintain problem-solving records.
- Track daily coding streaks.
- Monitor progress and identify weak topics.
- Keep notes and revision records.

🛠️ Tech Stack

- Language: Python
- Database: SQLite
- GUI: Tkinter / CustomTkinter (planned)
- Visualization: Matplotlib (planned)
